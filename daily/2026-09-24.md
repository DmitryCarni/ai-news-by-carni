# ИИ новости: 24 сентября 2026

## Где ИИ становится продуктом {#applied}

### Gemini получил живой видеоаватар

Google запустила Gemini 3.8 Live with Live Avatar в Gemini Enterprise. Агент слушает, видит и отвечает через видеоаватар, может вызывать инструменты без остановки разговора и переключаться между 97 языками.

Источник: Google, 24 сентября 2026.

## Архитектура и технологии внедрения {#stack}

### REST API становятся MCP-инструментами

Google Cloud добавила нативный MCP-сервер в API Gateway. Существующие REST API через OpenAPI можно предоставлять агентам как инструменты без отдельного MCP-слоя.

Источник: Google Developers, 24 сентября 2026.
