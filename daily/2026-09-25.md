## Фундаментальные тренды {#fundamental}

### Microsoft превращает Copilot из набора функций в постоянного рабочего агента

Microsoft представила обновлённый Copilot с тремя крупными режимами: Home, Code и Autopilot. Home объединяет чат, Cowork и привычные рабочие приложения; Code переносит агентную разработку в общий Copilot-контур; Autopilot должен выполнять длительные задачи в фоне и продолжать работу без постоянных новых команд пользователя.

Autopilot — развитие ранее показанного Microsoft Scout. Компания описывает его как постоянного персонального агента со своей памятью, рабочим пространством и облачным компьютером. Home и Code начинают распространяться через Frontier, а Autopilot должен выйти в закрытое тестирование в конце сентября.

Рыночный сдвиг здесь не в ещё одной вкладке интерфейса. Microsoft стягивает разговорный ИИ, работу с документами, код и длительных агентов в одну рабочую среду. Для компаний это постепенно меняет сам объект внедрения: вместо покупки отдельных AI-функций появляется единый слой, который получает контекст, инструменты и право продолжать работу между запросами.

### Claude получает независимо проверенный результат на девяти петлях

Anthropic опубликовала разбор эксперимента в теоретической физике: её исследователи с помощью Claude Science поручили модели вычислить шестичастичную амплитуду в планарной N=4 super Yang–Mills на девяти петлях. Это задача из области, где ручные вычисления быстро становятся крайне сложными.

Ключевой момент — результат не остался внутренней демонстрацией Anthropic. Физик Лэнс Диксон из SLAC/Stanford независимо проверил вычисление, используя другой теоретический маршрут. В публикации также отмечено, что Anthropic обратилась к нему за проверкой ещё 1 сентября, а итоговый разбор вышел 25 сентября.

Для scientific AI это более сильный сигнал, чем красивое решение задачи из известного набора. Ценность возникает там, где модель помогает получить новый сложный результат, а затем он выдерживает независимую предметную проверку. Пока это единичный исследовательский кейс, но он показывает, как AI-системы могут входить в реальный цикл «гипотеза → вычисление → внешняя верификация».

## Где ИИ становится продуктом {#applied}

### Proaction превращает персонализированные демо в программируемый этап продаж

OpenAI опубликовала кейс Proaction, разработчика ПО для управления автопарками. Компания использует Codex, GPT-Live-1 и GPT-6 Astra не только в разработке, но и для подготовки персонализированных интерактивных демо под конкретных потенциальных клиентов.

По оценке сооснователя Proaction, автоматизация четырёх–шести таких демо в месяц экономит 40–60 инженерных часов. Компания также сообщает, что доля сделок, переходящих после первого контакта к разработке решения вместо режима долгого прогрева, выросла на 50–60%.

Это данные самого клиента в кейсе поставщика, а не независимый аудит, поэтому важнее не абсолютные проценты, а сам паттерн. AI-кодинг начинает приносить эффект не только через скорость разработки продукта: он сокращает стоимость пресейла и позволяет быстрее собирать работающие доказательства ценности для конкретного покупателя.

## Возможности для бизнеса {#monetization}

### Продавать не презентацию, а работающий прототип под клиента

Кейс Proaction показывает практичную нишу для AI-разработки: вместо универсального демо быстро собирать ограниченный прототип, который использует данные, терминологию или процесс конкретного клиента. Это особенно ценно в B2B-продажах сложного ПО, где между «интересно» и «понятно, как это будет работать у нас» обычно лежит дорогая инженерная работа.

MVP можно строить вокруг одного повторяемого пресейл-сценария: шаблон приложения, ограниченный набор интеграций, изолированная тестовая среда и агент, который адаптирует демонстрацию под требования сделки. Измерять стоит часы инженеров на демо, время от первого контакта до технической проверки и долю сделок, которые переходят на следующий этап.
