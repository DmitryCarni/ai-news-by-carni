## Fundamental trends {#fundamental}

### AI infrastructure turns into a $10.3 trillion investment cycle

An estimate by economist Stijn Van Nieuwerburgh, cited in analysis of the US AI infrastructure build-out, puts data-center and related AI infrastructure spending at roughly $10.3 trillion between 2025 and 2032. The figure covers far more than buildings: accelerators, memory, networking, power generation and interconnects, substations, cooling and long-haul connectivity all sit inside the same industrial build-out.

The shift is that AI no longer looks like a normal server refresh cycle. It is becoming a capital-intensive industrial project where compute, power, networks, construction and financing can all become bottlenecks at once.

## Where AI becomes a product {#applied}

### Gemini gets a live video avatar for enterprise agents

Google made Gemini 3.8 Live with Live Avatar generally available in Gemini Enterprise. The agent can present a synchronized video avatar, continue a conversation while tools run in the background, understand live camera or screen input and automatically switch across 97 languages.

This is more than another voice interface. The agent becomes a visually present participant that can talk to a user and act through tools at the same time — a useful model for support, sales, training and self-service kiosks.

### Feedzai embeds the Farol agent directly into fraud operations

Feedzai launched Farol, an AI agent embedded inside RiskOps Studio. It analyzes fraud-rule performance, summarizes case context and helps investigators work through suspicious activity without moving data into a separate AI interface.

The integration model matters: the agent lives inside the operational system that analysts already use. That lowers adoption friction and keeps permissions, context and auditability closer to the actual workflow.

## Architecture and deployment {#stack}

### REST APIs become MCP tools without a separate server layer

Google Cloud added remote MCP-server support to API Gateway. Existing REST APIs described with OpenAPI 3.x can be exposed to agents as MCP tools without building and operating a separate MCP server.

The architectural payoff is reuse: the gateway keeps handling authentication, quotas and logging while the agent gets a standard way to discover and call tools. Existing enterprise APIs can become agent-facing capabilities without duplicating the whole control plane.

## Finance {#finance}

### Island raises $400 million as demand grows for AI-agent control

Island announced a $400 million Series F at a $6.4 billion valuation. The company positions its enterprise browser as a control plane that gives organizations visibility, policy enforcement and auditing for both people and AI agents interacting with corporate applications.

The round is a strong market signal that agent governance is becoming its own investment category. As agents receive more access to browsers, data and external services, companies need a layer that constrains actions, controls context and preserves a verifiable audit trail.

## Business opportunities {#monetization}

### AI-agent action control becomes a standalone product layer

Island, Gemini Live and Feedzai point to the same emerging market: companies need more than the agent itself. They need permissions, context controls, approval gates, observability and auditable action histories around it.

For integrators, the product can be the governed operating layer around existing agents and software rather than another chatbot. It can start with a browser or one business system and expand into CRM, ERP, finance and external APIs.

### REST-to-MCP becomes a new integration-services category

If an existing REST API can be exposed to agents through the gateway without a dedicated MCP server, the economics of integration change. Value shifts toward tool descriptions, access policy, OpenAPI quality, observability and deciding which actions an agent should actually be allowed to perform.

That lowers the entry barrier for smaller integrators: auditing existing APIs, preparing OpenAPI contracts, enabling MCP access and setting security policy can be sold as a focused project without building a full agent platform.

At the interface layer, Gemini turns the agent into a visual conversational presence. Inside banking, Feedzai embeds an agent directly into fraud operations. In architecture, Google makes existing REST APIs easier for agents to use. Around all of it, governance, security and auditing are becoming a market of their own.
