# AI News: September 24, 2026

## Where AI becomes a product {#applied}

### Gemini gets a live video avatar

Google launched Gemini 3.8 Live with Live Avatar in Gemini Enterprise. The agent can listen, see, respond through video, call tools without interrupting the conversation and switch across 97 languages.

Source: Google, September 24, 2026.

## Architecture and deployment {#stack}

### REST APIs become MCP tools

Google Cloud added native MCP server support to API Gateway. Existing REST APIs described with OpenAPI can be exposed to agents as tools without a separate MCP layer.

Source: Google Developers, September 24, 2026.

## Day in review

Agent interfaces are becoming more natural while existing enterprise APIs are becoming easier to expose as agent tools.
