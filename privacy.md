# Политика конфиденциальности

AI News by Carni использует Google OAuth 2.0 и YouTube Data API только для автоматической загрузки видео на канал AI News by Carni.

Приложение запрашивает разрешение `https://www.googleapis.com/auth/youtube.upload`. Оно не запрашивает пароль Google-аккаунта и не получает доступ к Gmail, Google Drive, контактам или другим данным, не связанным с этим разрешением YouTube.

OAuth credentials и refresh token используются только серверной автоматизацией проекта и не публикуются в открытом доступе. Данные не продаются и не передаются третьим лицам для рекламы или маркетинга.

Доступ можно отозвать в настройках безопасности Google.

## Расширение AI News by Carni — Shorts Thumbnail

Расширение является внутренним инструментом проекта и распространяется только среди явно разрешённых пользователей.

Его единственная задача — загрузить в YouTube Studio точную обложку, заранее одобренную в AI News by Carni, и зафиксировать факт ручного нажатия пользователем кнопки сохранения.

Расширение:
- хранит локальный токен устройства в хранилище браузера;
- обращается к внутреннему backend AI News by Carni в Supabase для получения задания и одобренного файла обложки;
- работает только на страницах YouTube Studio, необходимых для редактирования конкретного видео;
- обрабатывает технические данные задания: ID видео, ожидаемый ID канала, SHA-256 файла обложки, MIME-тип и состояние сохранения в интерфейсе Studio.

Расширение не собирает историю просмотров браузера, поисковые запросы, пароли, переписку, контакты или данные Gmail/Google Drive. Оно не используется для рекламы, профилирования пользователей или продажи данных.

На сервере хранится хеш токена устройства и технические записи очереди, необходимые для проверки корректности публикационного процесса. Сам локальный токен не публикуется в репозитории.
