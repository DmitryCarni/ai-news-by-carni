# Политика конфиденциальности

AI News by Carni использует Google OAuth 2.0 и YouTube Data API только для автоматической загрузки видео на канал AI News by Carni.

Приложение запрашивает разрешение `https://www.googleapis.com/auth/youtube.upload`. Оно не запрашивает пароль Google-аккаунта и не получает доступ к Gmail, Google Drive, контактам или другим данным, не связанным с этим разрешением YouTube.

OAuth credentials и refresh token используются только серверной автоматизацией проекта и не публикуются в открытом доступе. Данные не продаются и не передаются третьим лицам для рекламы или маркетинга.

Доступ можно отозвать в настройках безопасности Google.
